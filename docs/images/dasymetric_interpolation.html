Dasymetric interpolation: FCC place / county coverage → census blocks
FCC publishes coverage summaries for places and counties. We spread each summary's unit total across its census blocks in proportion to Census housing units, so every block gets an estimate — and the estimates add back up to the FCC totals exactly.
Inputs
Four sources
  • FCC place summary: total units + % of units at each technology × speed tier
  • FCC county summary: same, per county
  • Census housing units per block (Address Count Listing) — the weight
  • Census block assignment file: block → place (if any) and county
➤
Step 1
Blocks inside a place
Spread the place's FCC units by housing share; every block inherits the place's %.
w(b) = HU(b) ÷ HU(place)
U(b) = units(place) × w(b)
% (b) = % (place)
➤
Step 2
Blocks outside any place
Take what the county has left after its places, then spread that residual the same way.
units(resid) =
  units(county)
  − Σ units(place)
% (resid) =
  (county count −
   Σ place counts)
  ÷ units(resid)
U(b) = units(resid) × w(b)
Residual clamped at 0; places that cross county lines are split first.
➤
Step 3
Roll up to tract
Sum block counts, then rebuild the %. Weight by the FCC units each block received, not by housing units.
count(b) = U(b) × % (b)
% (tract) =
  Σ count(b) ÷ Σ U(b)
➤
Step 4
Conservation check
Re-add the block counts to county level and compare with the FCC source. They must match up to rounding; a gap means a bug, so the pipeline halts.
Σ count(b in county)
  = % (county) × units(county)
Worked example — one county, one place, gigabit fiber share
FCC says: County = 1,000 units, 40% gigabit fiber (400 units). Place P = 600 units, 50% (300 units). So the residual outside P = 400 units at (400 − 300) ÷ 400 = 25%.

Tract roll-up: if a tract holds B3 and R1, its share = (150 + 75) ÷ (300 + 300) = 37.5% — weighted by U(b). Note R1 has only 150 housing units but receives 300 FCC units, because the residual's units are spread across only 200 housing units.
Why the totals always balance
Every block in a place carries the same %, and the place's units are split into shares that sum to 1. So however housing units spread the units, the place's count is unchanged. The same holds for the county residual.
50 + 100 + 150 + 75 + 25 = 400
= 40% × 1,000 (FCC county figure)
✓ Exact, up to rounding
Checked on every run at county grain (monitoring.data_contract). A breach signals a bug in the share / residual math, not data drift.
Limitation: every block in a place gets the same %, so street- and neighborhood-level differences within a place are not captured.
